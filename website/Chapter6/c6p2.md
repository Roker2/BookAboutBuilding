# Параграф 2: Базовые команды Linux

Тут приведены базовые команды, которые используются практически в любом дистрибутиве Linux. Если вы впервые работаете с Linux, этот параграф может быть полезным.

::: tip Переход между директориями

```bash
cd path/to/folder # переход в директорию path/to/folder
cd ..             # переход в предыдущую директорию
cd ~/             # переход в домашнюю директорию
```

:::

Все три примера можно комбинировать как угодно, хоть `~/roms/los232/device/../vendor/xiaomi/mido`.

::: tip Вывести текущую директорию

```bash
pwd
```

:::

::: tip Создать директорию

```bash
mkdir path/to/new_folder        # создать директорию new_folder в уже существующей path/to
mkdir -p path/to_new/new_folder # создать последовательно директории to_new и new_folder
```

:::

::: tip Создать пустой файл

```bash
touch path/to/file
```

:::

::: tip Удаление

```bash
rm path/to/file # удалить файл
rm -r path/to   # удалить папку вместе с директориями и файлами
```

:::

::: tip Вывод содержимого

```bash
cat  # вывод всего содержимого файла
less # более удобный вариант просмотра файла, по которому можно листать стрелками, выход по клавише q
```

:::
